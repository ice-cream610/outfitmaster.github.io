# 验证记录 · 2026-10-14

环境：Windows，Node.js 25.8.0；项目要求Node.js 24或更高。

## 已通过

- `npm test`：32项，包括原前端回归、整套约束、锁定、局部替换、预算失败、冷启动、需求更新、模型输出校验、取消、HTTP与SQLite接口、真实商家资料与照片哈希、E原参考图保持不变、规格金额和会话版本冲突。
- `npm run build`：TypeScript严格检查及生产构建通过。
- 浏览器：Edge无头模式，1440px桌面与390px手机，验证真实商家照片、多图详情与官网链接、E原角色、特定商品组合对应效果、切换组合不复用错误图片、待生成与未配置状态、材质验证样例、3套方案、锁定、局部替换、预算失败恢复、购物清单、收藏与离线回退。没有未捕获页面异常，手机无横向溢出。
- 素材核对：92件真实商品、276张原商家照片，所有本地引用存在并校验照片哈希；原E参考图逐字节哈希保持与用户提供版本一致。
- 内置image_gen实际生成两类样本：用户大衣×E1，以及三件真实商家商品×E1。后者因首版比例偏长做了一次修正，保留被舍弃版本于 `docs/visual-review/`。
