# 精选衣橱 · 整套推荐体验

「发现好物」保留单品入口。「精选衣橱」独立推荐完整套装，不要求先选一件商品。两条路径在桌面、手机导航中均可进入。

## 页面与行为

- `/#wardrobe`：12 套服饰组合，以长直发 AI 形象封面展示，附场景、风格、件数、简单介绍和整套参考起价。默认先展示四种主题的主搭配，再展示替换组合。
- 场景、风格、整套预算共同筛选；金额按整套所有单品的可售尺码最低价计算，不按勾选商品的价格筛选。选择尺码后，实际勾选金额按对应 SKU 重算。
- 偏好保存在当前浏览器。无匹配结果时显示空状态和重置入口，不静默超预算或推荐不符标签的组合。当前为有限预设匹配，没有伪装成模型推理或学习购买概率。
- `/#set/<id>`：整套效果、形象缩略图、上身/下装局部放大、搭配介绍和所有单品。四套主搭配各有四种形象；八套替换组合各有长直发形象，局部视图是原图放大，不是新生成的角度。其他服饰组合另列，点击后才切换商品清单。
- 勾选只改变购买清单，不改变展示的衣服。可全选或部分购买；选中的每件必须选择可售尺码，每个规格限 1 件。未勾选项不要求尺码、不计入订单。
- 加购物袋保存实际选中 SKU，重复加相同规格不重复堆叠；可打开购物袋查看金额、清空。
- 立即购买先显示明细、尺码及金额，确认后保存本地模拟订单并显示订单号。刷新后可从「模拟订单」查看。无付款、真实下单或商家订单创建。
- 单品详情链接保留返回套装路径；从商品详情进入原穿搭工作台的流程保留。

## 代码阅读路径

1. `src/curated/Commerce.tsx`：两个 tab、套装路由和单品返回路径。
2. `src/curated/sets.ts`：套装列表、精确图片集合、偏好匹配、金额、购买校验与购物记录。
3. `src/curated/Wardrobe.tsx`：列表、筛选、详情、购物袋及订单确认。
4. `src/curated/wardrobe.css`：沿用暖色视觉，独立套装卡片和响应式详情布局。

本地存储键为 `om.curated.set-preferences.v1` 和 `om.curated.set-shopping.v1`。图片复用已归档的预生成资产，没有修改商品原图和原穿搭工作台。
