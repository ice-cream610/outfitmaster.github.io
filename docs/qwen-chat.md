# Qwen3.8-Flash 穿搭对话

当前 `/#outfit/<商品ID>` 右侧对话接入真实 Qwen3.8-Flash。保留用户确认的三栏界面、E 角色、手动换装与预生成效果。对话通过服务端调用，前端没有密钥。

## 本地配置

在项目根目录将 `.env.example` 复制为 `.env`，填写：

```dotenv
DASHSCOPE_API_KEY=你的百炼API密钥
QWEN_BASE_URL=https://你的业务空间ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
QWEN_MODEL=qwen3.8-flash
```

地址只是格式示例：请复制百炼控制台实际提供的 OpenAI 兼容 Base URL；密钥和地址必须属于同一地域/业务空间。不要加 `/chat/completions`，不要把密钥放进 `VITE_` 环境变量。已有可用的旧版兼容地址也可以填写。

保存后重新运行 `npm run dev`，打开 `http://127.0.0.1:5176/`。前端 5176 将 `/api` 转发至后端 8787。仅静态 GitHub Pages 无法运行对话接口。界面显示“待连接”时，手动换装仍可使用；不会冒充模型成功。

`MODEL_*` 是旧 `/#agent-lab` 配置，`IMAGE_*` 是旧图片生成接口，均与本次对话独立。`.env` 已被 Git 忽略。

## 固定工作流与职责

1. 校验输入：当前搭配必须对应真实存在的完整商品集合和 E 形象。锁定/购买项必须属于当前集合；需求最多 2000 字，历史最多 12 条。
2. 需求解析：第一次 Qwen 请求只处理文字，读取当前状态、最近历史和随方案保存的偏好。输出预算、改动品类、保留/排除商品、场景风格和需要视觉判断的条件。
3. 程序筛选：只在已有 24 个角色效果（12 套服饰组合）中查找。严格保留形象、锁定项和未指定替换的品类，检查来源、可售快照、预算和“比现在便宜”。没有候选则停止，省下视觉调用，保留原方案。
4. 视觉比较：第二次 Qwen 请求读取候选涉及的真实商家商品照片（每个 SKU 一张主图，去重后以 Base64 发送），比较整套配色、廓形、材质和场景。只能返回候选 renderId，或者明确无匹配。
5. 校验并应用：服务器再次校验候选和图片映射；客户端预载图片，再一起更新商品与效果。新商品不自动勾选购买。预算与偏好随版本保存，撤销/恢复会一起恢复。

程序没有提取/保存模型内部思维链。`server/prompts/curated-intent.md` 和 `curated-rank.md` 是可修改的系统提示词；`server/curated-chat.mjs` 是编排、筛选与校验框架；`server/qwen.mjs` 是模型连接层；`src/curated/services.ts` 和 `App.tsx` 负责页面联动。

最新一次运行记录写入 `.runtime/curated-chat-latest.json`：包含结构化需求、候选 ID、可核验的简短评审依据、Token 用量和耗时，不记录密钥、Base64 图片或模型隐藏推理。记录覆盖上一次；本地目录不提交 Git。可用于定位到底是需求解析、候选不足还是视觉判断出了问题。

## 当前边界

- 视觉理解是真实调用，人物展示仍使用预生成资产，不是实时试衣；短发/卷发/马尾现有变体较少，候选可能为空。
- 外观、风格等判断仍可能出错。金额/锁定/品类/图片集合由程序硬校验；“不要红色”等要求需要模型识别商品属性与视觉复核，不保证绝对正确。加入新套装须先补齐图片映射，再进入候选。
- 对话不自动解锁或下单；用户要求改发型时打开原有形象面板。金额是商家快照的人民币估算。
- 一次推荐最多两次调用，无无界循环、无自动付费重试；单次模型请求 45 秒超时。页面支持取消/重试；过期结果不会覆盖当前版本。最多同时处理两个对话请求，非正式公网服务。
- 只返回一套推荐，以便明确应用；可继续对话。首次进入仍展示既有默认搭配，此次范围是对话调整。
- 历史取最近 12 条，成功方案携带最多 12 条持续偏好。没有成功应用的需求只保留在对话历史中，特别长的失败对话可能丢失早期要求。
- 手动切换整套或应用筛选会清除方案中保存的对话偏好，以用户新的主动选择为准；只改形象会保留这些偏好。

## 验证与优化

`npm test` 测试硬约束、HTTP 调用链、鉴权错误、不合法模型输出和取消；默认不会调用真实付费服务。

`node scripts/verify-qwen-live.mjs` **会调用真实付费模型**：验证只换牛仔裤、100 元不可能预算、恢复预算后多轮换回条纹长裤。记录在 `.qa/qwen-live.json`。浏览器检查脚本可模拟取消/失败并选择真实对话模式。

后续先收集一批你认可/不认可的需求与搭配作为验收集，分别统计需求解析准确率、约束违例率、整套偏好命中率、延时和 Token；再调整提示词或候选库。不要把模型自己的评分当成客观审美结论。

2026-10-15 本机验收：54 项自动化测试与正式构建通过；真实 Qwen 调用完成“仅换牛仔裤 → 100 元预算不匹配 → 恢复预算并换回条纹裤”；真实浏览器完成对话换装与撤销。模拟故障验证取消、重试、缺少配置；原商城、商品详情、形象调整、保存、购物与移动端回归通过。上述是有限用例验证，并非通用审美准确率评测。

官方接口依据（2026-10-15 核对）：[模型信息](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)、[Chat Completions](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions/)、[图片输入](https://help.aliyun.com/zh/model-studio/vision)。本实现显式关闭 thinking，使用 JSON 输出和多图输入。
